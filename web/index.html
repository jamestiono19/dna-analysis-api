How the results are calculated

Alignment score

Global alignment adds up one score per column.

Score per alignment column
Matching bases+1
Different bases−1
Gap, per base−2
Any column with N0

Identity

The share of alignment columns where both sequences have the same A, C, G or T base. Gap columns and columns with N count as not identical.

identical columns ÷ all columns

Variant positions

  • Substitutions and deletions are numbered by reference base, starting at 1.
  • Insertions are numbered by the reference base before them. Position 0 means before base 1.
  • Neighbouring inserted or deleted bases are reported as one event.
